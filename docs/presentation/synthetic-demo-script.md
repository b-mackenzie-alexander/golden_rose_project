Concept demonstration disclaimer: This is a local-only concept demonstration using fictional synthetic data. It is not authenticated and is not connected to real client data.

Screenflow narrative (8 minutes):

1) Agency dashboard
- Action: open the dashboard, point out the four metrics plus three actionable request cards, then use the language toggle once to show the same pages in Spanish.
- Value statement: staff can see the immediate queue, concrete due times, and the selected request summary without leaving the agency workflow.
- Limitation/non-claim: this is a fictional, local concept preview and does not represent live agency production capacity; the translation shown is a basic presentation-layer toggle, not a completed legal/content localization program.

2) Open request detail
- Action: click `Open request overview` on any request card or use the top `Request detail` navigation.
- Value statement: shows one concrete employer request with role, broad area, source, coordinator note, due time, and staff activity trail.
- Limitation/non-claim: no writes are persisted; all data resets on refresh.

3) Add records from paper
- Action: click `Add records`, then click `Add synthetic employer draft` and `Add synthetic worker draft`.
- Value statement: shows the first-rollout operational win: staff can manually convert paper employer sheets and worker registration packets into shared draft records that another workstation could continue reviewing.
- Limitation/non-claim: this is an in-memory presentation state only; it is not connected to a live database.

4) Worker view
- Action: click `Open worker request page` from request detail, then click `Open interest request`.
- Value statement: shows how a worker-safe opportunity can expose broad area, schedule, and agency follow-up without pretending an automated staffing decision happened.
- Limitation/non-claim: the action opens a preview of a human-reviewed request handoff; it does not rank, place, or screen anyone.

5) Employer view
- Action: click `Employer view` or `Open employer status page`, then click `Open update preview`.
- Value statement: shows request status, milestone trail, next update time, and employer-safe summary without exposing worker identity or private contact information.
- Limitation/non-claim: this is a status preview, not an employer self-service production portal.

6) Back to request detail + follow-up
- Action: return to `Request detail` and click `Show staff follow-up`.
- Value statement: demonstrates a bounded staff coordination update that changes the current presentation state and appears in the activity trail.
- Limitation/non-claim: the interaction is synthetic and intentionally reset-on-refresh.

7) Close with demo value
- Action: return to `Agency dashboard` and recap the path.
- Value message: the platform value is coordinated, privacy-conscious operational visibility where staff actions stay accountable and human review remains central.
